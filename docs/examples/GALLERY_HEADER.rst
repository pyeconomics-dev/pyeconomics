Example gallery
===============

Short scripts, at least one for each domain of the library. Each one runs when
this documentation is built, offline, on inputs typed into the script, so what
you see is what the code printed and drew. Copy a script and change its numbers:
the only thing it needs is ``pip install "pyeconomics[plot]"``, and the extra is
only for the charts.

For the ideas behind the numbers, see the
:doc:`Python-for-finance tutorials </tutorials/finance/index>`. To change an
input without installing anything, try the
:doc:`in-browser examples </wasm/index>`.

These examples are educational, not investment advice.
