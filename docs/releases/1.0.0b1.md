# pyeconomics 1.0.0b1 - 2026-10-28

The rehearsed candidate `1.0.0b1.dev1` (`3a9fde9c460d853dd92f544d1490dca1d592bc66`)
received the maintainer's GO on 2026-10-28; see the
[readiness evidence](https://github.com/pyeconomics-dev/pyeconomics/blob/v1.0.0b1/docs/releases/1.0.0b1-readiness.md).
The Python floor was re-checked on 2026-10-28 and remains 3.12.
The permanent ledgers record all 50 model, 31 provider and 171 concept ids,
unchanged from `1.0.0a2`.

This is the first beta of the rebuilt library (`1.0.0b1`). It delivers the
programmatic surfaces specified by
[ADR-0012](https://github.com/pyeconomics-dev/pyeconomics/blob/v1.0.0b1/docs/adr/0012-programmatic-surfaces.md):
the framework-free surface core (`pyeconomics.surfaces`) and deterministic
`registry.json` export, the `pyeconomics` command line, tabular and document
exports (`csv`, `xlsx`, `parquet`, `arrow`, `json`) and `.zip` reproducibility
bundles, the FastAPI REST API (`pyeconomics serve`, `pyeconomics[server]`) in
local and hosted modes, the MCP server (`pyeconomics mcp`, `pyeconomics[mcp]`)
over stdio and stateless Streamable HTTP with MCP Apps interactive charts and
the official MCP Registry entry (`io.github.pyeconomics-dev/pyeconomics`), the
cross-surface parity suite, the optional AI narrative (`pyeconomics.ai`), the
hardened multi-stage container image, and the staging deployment on Google
Cloud Run behind Cloudflare Zero Trust Access and a Cloudflare Worker.
**Pre-releases carry no stability promise** under
[ADR-0003](https://github.com/pyeconomics-dev/pyeconomics/blob/v1.0.0b1/docs/adr/0003-versioning-and-deprecation.md).
Inputs, outputs, manifests, CLI flags, routes, tool schemas and Python APIs may
change between pre-releases. The 0.2.6 stable release remains available and
receives security fixes until 1.0.0.

## Surface core, registry export and cross-surface parity

Every surface runs models through `pyeconomics.surfaces.invoke(model_id, inputs, *, bind=None, mode=None, llm_use=None)`
and returns `Result.to_json()`'s RFC 8785 canonical JSON bytes unchanged.
Every `PyeconomicsError` subclass maps through one error table
(`pyeconomics.surfaces.problems`) to an RFC 9457 `application/problem+json`
document (`https://pyeconomics.dev/problems/<slug>`), an HTTP status code and a
CLI exit code (`0` to `8`, `2` for command-line usage), scrubbed of credentials,
file paths, hosts and upstream URLs.

`pyeconomics.surfaces.registry_export.write_registry(path)` (and
`pyeconomics registry export --out DIR`) exports `registry.json` — every
model's specification, JSON Schema 2020-12 input and output schemas, Markdown
model card, canonical example result and Plotly figure — validated against
`REGISTRY_SCHEMA` (`https://pyeconomics.dev/schemas/registry/1.json`). Snapshot
tests pin every model's input and output schema, the registry schema, the
OpenAPI 3.1 document and the MCP `tools/list` output. The cross-surface parity
suite (`tests/parity/` and `scripts/parity/check_installed.py`) verifies that
the Python API, the CLI, the REST API and the MCP server return byte-identical
canonical JSON across every golden case of all 50 model families and every
bound calculation, and that no surface module hand-writes a command, route or
tool for an individual model.

## The `pyeconomics` command line

Installed with the core package (Cyclopts, loaded lazily on invocation), the
`pyeconomics` console script provides:

- `pyeconomics models list|search|describe|run`: `models run <id>` generates one
  `--<field>` flag per model input field from its schema, accepts JSON via
  `--inputs FILE` or `-` (standard input), binds live data with `--as-of`,
  `--vintage`, `--profile`, `--concept FIELD=ID` and `--param NAME=VALUE`, runs
  batches with `--batch FILE`, and narrates results with `--narrate`.
- `pyeconomics data search|get|describe|vintages|sources`: queries catalog
  concepts (`us.inflation.cpi.yoy`) or provider series (`bls:CUUR0000SA0`),
  reporting source attributions, required notices and disabled status.
- `pyeconomics keys set|list|delete`: stores API keys in the OS keyring from a
  hidden prompt or `--stdin` (never a command-line argument) and reports each
  configured key's source kind (`env`, `dotenv`, `keyring`, `none`), never its
  value.
- `pyeconomics cache ls|info|clear|path`, `pyeconomics registry export --out DIR`,
  `pyeconomics bundle check FILE`, `pyeconomics serve` and `pyeconomics mcp`.

## Exports and reproducibility bundles

`pyeconomics.exports` and `--format json|csv|xlsx|parquet|arrow` / `--bundle`
write results and data frames through a single layout layer so every format
carries the data's attributions, licence notices, terms URLs and provenance
manifest:

- **CSV:** UTF-8 with LF line endings, a leading `#` metadata header, and
  formula-injection escaping (`escape_text` prefixes text cells starting with
  `=`, `+`, `-`, `@`, tab, CR or LF with `'`, while numeric cells remain
  unquoted numbers).
- **XLSX:** `data` and `manifest` sheets written with shortest round-trip
  floating-point text so Excel preserves full IEEE 754 precision.
- **Parquet and Arrow:** written lazily through `pyarrow` with the manifest and
  attributions embedded in the Arrow schema metadata (`pyeconomics.manifest`).
- **Reproducibility bundles (`.zip`):** deterministic archives containing
  `result.json`, `inputs.json`, `request.json`, `manifest.json`,
  `ATTRIBUTION.txt`, `requirements.txt`, `reproduce.py` and `README.txt`.
  `pyeconomics bundle check FILE` verifies the archive's JSON members without
  executing code from the zip, and `python reproduce.py` recomputes the result
  and verifies `result_sha256`.

## REST API, hosted mode, container and staging

The `server` extra (`fastapi>=0.162`, `uvicorn>=0.54`, `limits[redis]>=5.8`)
powers `pyeconomics.server.create_app` and `pyeconomics serve`:

- **Routes:** `GET /v1/models`, `GET /v1/models/{model_id}`,
  `POST /v1/models/{model_id}/run`, `GET /v1/models/{model_id}/run?inputs=<base64url>`
  (with `ETag: W/"<result_sha256>"`, `If-None-Match` -> `304`, and
  `Cache-Control`), `GET /v1/series/{target}`, `GET /v1/sources`,
  `GET /healthz`, `GET /version`, `GET /openapi.json`, and `POST /mcp`.
  `?format=csv|xlsx|parquet|arrow|bundle` downloads any run or series through
  the exports.
- **Worker pool and budgets:** Model runs and series fetches execute in spawned
  worker processes (`PYECONOMICS_WORKERS`) communicating over length-prefixed
  canonical JSON headers and raw bytes (never `pickle`), enforced by per-model
  `CostClass` wall-clock budgets (`2s` instant, `10s` light, `30s` heavy in
  hosted mode).
- **Local vs. hosted mode:** Local mode binds `127.0.0.1` and rejects
  non-loopback `Host` headers (`400 host-not-allowed`) unless `--allow-remote`
  is set. Hosted mode (`PYECONOMICS_MODE=hosted`) verifies `X-Pyeconomics-Edge`
  in constant time (`403 edge-required`), enforces per-IP moving-window rate
  limits (`60/min` runs, `30/min` series, `120/min` metadata; `429 too-many-requests`
  with `Retry-After`) backed by Upstash Redis over TLS (`rediss://`, failing
  closed with `503 limits-unavailable` for runs and series), and refuses any
  data source not classed `hosted-safe` or `user-supplied` (`403 licence-refused`).
- **Container and staging:** The multi-stage `Dockerfile` builds a non-root
  (`10001:10001`) Python 3.14 image scanned by Trivy (`0` fixable Critical or
  High vulnerabilities) with a CycloneDX SBOM. Merges to `main` deploy to
  Google Cloud Run (`us-central1`) via Workload Identity Federation behind a
  Cloudflare Worker and Cloudflare Zero Trust Access at
  `https://staging-api.pyeconomics.dev`, probed hourly by `staging-health.yml`.

## MCP server, MCP Apps and the MCP Registry

The `mcp` extra (`mcp>=2.3`) adds `pyeconomics mcp` over stdio (`uvx --from "pyeconomics[mcp]==1.0.0b1" pyeconomics mcp`)
and stateless Streamable HTTP (`--transport http` on `127.0.0.1:8765`, or `/mcp`
on the REST server), implementing MCP specification `2026-07-28` (`server/discover`)
and earlier revisions (`2024-11-05` to `2025-11-25`):

- **Tools:** 5 discovery and data tools (`search_models`, `describe_model`,
  `run_model`, `get_series`, `list_sources`) plus 16 headline model tools
  (`corporate_capital_budgeting`, `corporate_cost_of_capital`,
  `derivatives_binomial_tree`, `derivatives_black_scholes_merton`,
  `equity_dividend_discount`, `equity_free_cash_flow`,
  `fixed_income_bond_pricing`, `fixed_income_curve_bootstrap`,
  `fixed_income_duration`, `foundations_returns`, `foundations_time_value`,
  `international_parity_conditions`, `macro_policy_rule`,
  `performance_risk_adjusted`, `portfolio_mean_variance`,
  `risk_value_at_risk`), each with self-contained JSON Schema 2020-12
  `inputSchema` and `outputSchema`.
- **`llm_use` gate:** MCP tool calls and AI narratives pass `LlmUsePolicy` into
  the resolver and `surfaces.gate.check_document`, skipping sources whose terms
  forbid LLM use (`fred` and `alfred` among them) with skip reason `llm_use` and
  refusing `unclear` sources unless `PYECONOMICS_ALLOW_UNCLEAR_LLM_USE=1` is set
  out of band at server startup.
- **MCP Apps and MCP Registry:** `ui://pyeconomics/chart` (`text/html;profile=mcp-app`)
  renders interactive Plotly.js 4.1.1 charts with Subresource Integrity and a
  strict CSP. `server.json` and `.github/workflows/mcp-registry.yml` publish
  `io.github.pyeconomics-dev/pyeconomics` to the official MCP Registry via
  GitHub OIDC.

## Optional AI narrative

`pyeconomics.ai.narrate(result, *, provider=None, model=None)` and
`pyeconomics models run ... --narrate` generate an opt-in plain-language
explanation of a `Result` using your own API key across four providers declared
over the data layer's HTTPS transport (`openai`, `anthropic`, `gemini`,
`openrouter`; zero AI SDK dependencies). The default (`openai` with
`gpt-6.1-sol`) was selected with the roadmodel ladder on 2026-10-26, and every
call reports its input/output token counts, estimated US dollar cost from a
dated price table (`2026-10-26`), and a "not investment advice" notice without
modifying the `Result` or its `result_sha256`. It is disabled until
`ai_enabled=True` (`PYECONOMICS_AI_ENABLED=1`), is refused in hosted and offline
modes, and enforces the `llm_use` gate before any request.

## Changes and fixes since 1.0.0a2

- **Thread-safe library warnings ([#157](https://github.com/pyeconomics-dev/pyeconomics/issues/157)):**
  `core.library_warnings` serializes wrapped `statsmodels` and `arch` fits with
  a re-entrant lock and routes warnings emitted on other threads back to their
  own handler, so concurrent model runs in one process never swap or lose
  warnings.
- **Provider disable switch ([#162](https://github.com/pyeconomics-dev/pyeconomics/issues/162)):**
  `PYECONOMICS_DISABLED_PROVIDERS` / `disabled_providers` disables any provider
  before cache reads or network requests (`SourceDisabledError`, `503
  source-disabled`, exit code `7`), and the catalog resolver skips disabled
  candidates automatically.
- **Dependencies:** Core runtime adds `cyclopts>=5.3` (and its pure-Python
  closure `attrs`, `docstring-parser`, `rich`, `rich-rst`, `markdown-it-py`,
  `mdurl`, `pygments`). `[server]` adds `fastapi>=0.162`, `uvicorn>=0.54` and
  `limits[redis]>=5.8`. `[mcp]` adds `mcp>=2.3` (with a reviewed licence
  exception for `pywin32` on Windows). `[all]` includes `[server]` and `[mcp]`;
  `[ai]` remains empty because `pyeconomics.ai` uses `HttpTransport` directly.
- **Unchanged model outputs and ledgers:** No model formula, golden output or
  released model/provider/concept ledger entry changed between `1.0.0a2` and
  `1.0.0b1`.

## Known limitations

- **Hosted `/v1/series/{target}` per-request upstream fetch until Phase 5:**
  In `1.0.0b1`, hosted `/v1/series/{target}` fetches `hosted-safe` originators
  per request through the worker pool under the `30/minute` per-IP rate limit
  and container SQLite cache. Pre-built Cloudflare R2 Parquet snapshots replace
  per-request upstream fetches in Phase 5.
- **Hosted-mode data scope and no hosted AI narrative until Phase 8:** Hosted
  mode serves only keyless `hosted-safe` and `user-supplied` data and refuses
  library-only, keyed, contact-required or opt-in sources (`403 licence-refused`)
  and AI narratives (`403 narrative-not-hosted`), naming the local CLI command
  to run instead.
- **No web application yet:** The hosted web application, model explorer and
  data explorer arrive in Phase 5.
- **CPython 3.15 wheel markers ([#154](https://github.com/pyeconomics-dev/pyeconomics/issues/154), [#182](https://github.com/pyeconomics-dev/pyeconomics/issues/182), owner `@nathanramoscfa`):**
  `econometrics.garch` (`arch>=8.0`) and the `fuzz` development group (`PyYAML`)
  carry `python_full_version < '3.15'` markers under the Wheel rule until
  upstream publishes CPython 3.15 wheels.
- **MCP `tools/list` schema size ([#197](https://github.com/pyeconomics-dev/pyeconomics/issues/197), owner `@nathanramoscfa`):**
