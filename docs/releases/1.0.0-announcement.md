## GitHub Discussions

**Title:** pyeconomics 1.0.0 is released, and pyeconomics.dev is open

pyeconomics 1.0.0 is out: an open library of 50 tested, cited economics and
finance model families across 13 domains, from the time value of money and bond
pricing to option pricing, portfolio construction, risk, econometrics and
monetary policy rules.

Every model has typed inputs with units and bounds, cited formulas and at least
three cited test cases, and every result carries a manifest that lets you
reproduce it. The same model answers the same bytes wherever you call it:

- **On the web:** [pyeconomics.dev](https://pyeconomics.dev) has a page and a
  calculator for every model, and a data explorer for public economic series.
- **In Python:** `pip install pyeconomics` (Python 3.12 or later).
- **On your own machine:** `pip install "pyeconomics[app]"`, then
  `pyeconomics serve`, runs the same site locally, with every data source on
  your own keys.
- **In an AI assistant:** the MCP server, `uvx --from "pyeconomics[mcp]"
  pyeconomics mcp`, or the hosted one at `https://pyeconomics.dev/mcp`.
- **From the command line or a REST API:** `pyeconomics models run ...` and
  `pyeconomics serve`.

The [documentation](https://docs.pyeconomics.dev/) has tutorials, how-to
guides and every model's card, and the
[release notes](https://github.com/pyeconomics-dev/pyeconomics/blob/main/docs/releases/1.0.0.md)
list what is in 1.0 and its known limitations. From 1.0.0 the public API follows
Semantic Versioning.

Coming from 0.2.x? It reached end of life with this release; the
[migration guide](https://docs.pyeconomics.dev/en/stable/migration.html) maps
each call to 1.0.

pyeconomics is free and open source under the Apache License 2.0. Questions,
bugs and model requests are welcome here in Discussions or as
[issues](https://github.com/pyeconomics-dev/pyeconomics/issues). A
[newsletter](https://pyeconomics.dev/newsletter/) carries occasional release news, and
[pyeconomics.dev/pro](https://pyeconomics.dev/pro/) describes a paid tier that
may be built if enough people want it; it does not exist yet and nothing is sold.

## Newsletter

**Subject:** pyeconomics 1.0.0 is released

Thank you for signing up. pyeconomics 1.0.0 is released, and
[pyeconomics.dev](https://pyeconomics.dev) is open to everyone.

- **50 model families across 13 domains,** each with cited formulas, tested
  cases and a manifest on every result.
- **A calculator for every model** at pyeconomics.dev, and a data explorer for
  public economic series.
- **`pip install pyeconomics`** for Python 3.12 or later, with the same models
  on the command line, a REST API and an MCP server for AI assistants.

Start with the [documentation](https://docs.pyeconomics.dev/), or read the
[release notes](https://github.com/pyeconomics-dev/pyeconomics/blob/main/docs/releases/1.0.0.md).
