## 11. Decision

The maintainer must write or explicitly approve the final GO or NO-GO line
in the PR conversation. The agent cannot supply that decision. Outstanding
evidence: tag approval, account/email confirmations, TestPyPI rehearsal and
attestations, clean published installs, correction of numerical defect #89, Python
3.15 policy disposition and NOTICE choice.

**Agent recommendation: NO-GO for this candidate.** The full suite found
a reproducible US 30/360 long-stub timing error in the shared bond flows
([#89](https://github.com/pyeconomics-dev/pyeconomics/issues/89), High
model-error). For issue 1993-05-30, settlement 1994-05-31, maturity
1995-04-15, annual frequency and zero coupon, expected Macaulay duration
is `1.875 - 1.0 = 0.875` under the declared convention; the model returns
`0.8722222222222222`. At 5% yield, full price is `95.83369261359005`
instead of QuantLib 1.43's `95.8207053225834`. The deterministic oracle
rerun also fails. Notional grid splitting of the non-additive US 30/360
count is the suspected cause; correction needs a dedicated fix branch,
golden regression and public erratum, model-version review, bumped `.devN`
and a fresh rehearsal. Python 3.15 policy issue #65 also needs resolution.
This recommendation is not a maintainer decision.

Nathan Ramos, CFA approved the NO-GO recommendation on 2026-10-12 in the
Codex session, instructing the agent to implement the recommendations in
full. That approval is relayed in this attempt's PR conversation. Issues
#89 and #65 must be fixed before a fresh readiness attempt; this document
preserves the rejected dev1 candidate's evidence, including unmet checks.
It does not mark roadmap Step 13 complete or authorize a PyPI release.

Decision: NO-GO — #89 US 30/360 long-stub timing error; #65 Python 3.15 support-policy gap.
