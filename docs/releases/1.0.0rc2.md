# pyeconomics 1.0.0rc2 - 2026-11-24

This is the second release candidate for pyeconomics 1.0.0. It is
[1.0.0rc1](https://github.com/pyeconomics-dev/pyeconomics/blob/v1.0.0rc2/docs/releases/1.0.0rc1.md)
with two fixes to the web app, found in production during rc1's soak. The
public API is unchanged and still frozen
([`docs/public-api.md`](https://github.com/pyeconomics-dev/pyeconomics/blob/v1.0.0rc2/docs/public-api.md)).
1.0.0 will be this candidate with only its version changed, once it has run in
production for three days and passed the launch readiness gate.

It is a pre-release: `pip install` installs it only when asked. Plain
`pip install pyeconomics` still installs 0.2.6, the stable release, until 1.0.0
ships. Python 3.12 or later is required.

```sh
python -m pip install --pre "pyeconomics==1.0.0rc2"
python -m pip install --pre "pyeconomics[econometrics,plot,server,mcp]==1.0.0rc2"
uvx --from "pyeconomics[mcp]==1.0.0rc2" pyeconomics mcp
```

The web app on your own machine:

```sh
python -m pip install --pre "pyeconomics[app]==1.0.0rc2"
pyeconomics serve
```

Then open `http://127.0.0.1:8000/`.

## Fixed since 1.0.0rc1

- **Select lists in the dark theme.** In the dark theme, every select's open
  list (a calculator's example and calculation, live data's profile, the data
  explorer's choices, the model filters) showed near-white text on white in
  Chrome on Windows: the options were transparent, and the browser draws a
  transparent list over white. Options now take the theme's own background and
  text colours, and a browser test reads every select's options in both themes
  ([#388](https://github.com/pyeconomics-dev/pyeconomics/pull/388)).
- **A run that gets no answer says why.** A calculator run or a data
  explorer read that something in front of the site redirected, such as a
  sign-in that had expired, said "the run was not sent". It now says it was
  redirected and to reload the page, and a request the network refuses keeps
  the browser's own reason
  ([#387](https://github.com/pyeconomics-dev/pyeconomics/pull/387)).

Neither changes a model, a result, a command, an endpoint or an MCP tool. The
`pyeconomics` wheel's code is 1.0.0rc1's member for member: only its metadata
differs, the version and the README's install lines. The `pyeconomics-app`
wheel carries the fixed site.

## How it was released

- **Why a second candidate.** rc1's soak began on 2026-11-20. On 2026-11-23
  the maintainer found the select lists unreadable in production, a High
  finding that the launch readiness gate cannot pass with open, and chose to fix
  it before launch. rc1's soak ended that day, and rc2 soaks in its place.
- **Rehearsal.** FILL
- **Release.** The `v1.0.0rc2` tag publishes both distributions to PyPI with
  provenances, deploys the candidate to production behind Cloudflare Access,
  where it is not indexed, and publishes the MCP Registry entry at 1.0.0rc2
  (stdio only, until the hosted endpoint is public).
- **Soak.** Three days in production, a length the maintainer set, during which
  only security fixes merge. It passes on the same criteria as rc1's: no
  unexplained server error, at least 99.5% uptime on the status page, every
  scheduled snapshot run green, every Sentry issue triaged, the production
  health check green, spend inside the budget and no Critical or High security
  finding open.
