# Python for finance

Four notebooks on the everyday programming of finance: holding results in tables,
working with returns, simulating what you cannot solve, and building portfolios.
They teach the Python and the ideas together, through pyeconomics, so every
formula is a model you can read about and every number comes with a record of how
it was made.

They assume you know a little Python and have worked through
{doc}`your first model </tutorials/first-model>`. Each one runs during every
documentation build, offline, on numbers typed into the page. Those numbers are
invented, and each page says so. They illustrate a method and say nothing about
any real fund or market.

```{toctree}
:maxdepth: 1

pandas-results
return-statistics
monte-carlo
portfolio-mathematics
```

Each page ends with its references, the papers and books where these methods
were first set out or are best explained. To try a calculation without installing
anything, use the {doc}`in-browser examples </wasm/index>`. For shorter scripts
across every domain, see the {doc}`example gallery </gallery/index>`.

These notebooks are educational, not investment advice.
