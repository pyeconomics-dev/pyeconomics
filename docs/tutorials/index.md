# Tutorials

Six short lessons that take you from an empty machine to a model, live data,
the command line, the REST API, the local web app and an AI assistant. Follow
them in order: each one builds on the last, and together they take a little over
an hour.

Every example runs in the test suite, offline, so what you read is what you get.
Output that comes from a data source is recorded, and each lesson says so.

```{toctree}
:maxdepth: 1

install
first-model
data-and-keys
command-line
rest-api
mcp
```

Once you know your way around, the {doc}`how-to guides </how-to/index>` give
recipes for particular jobs, such as getting a result into R or Excel, and the
reference pages describe every model, source and option. The
{doc}`Python-for-finance tutorials </tutorials/finance/index>` are a separate
track on the ideas behind the numbers. Moving from 0.2.x? Start with the
{doc}`migration guide </migration>`.
