# How-to guides

Recipes for one job each, for when you already know your way around. New to
pyeconomics? Start with the {doc}`tutorials </tutorials/index>`.

Each Python and shell example runs in the test suite, offline. The test suite
has neither R nor Excel, so the examples in those languages are recipes to try
on your own version.
